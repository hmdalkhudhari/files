  1. 1ثبّت السكيلات بـClaude Code (رقم ١).
  2. 2عرّف Claude على أسلوبك بملف voice.md (رقم ٢)، وهذي أهم خطوة.
  3. 3جرّب /ig-reel بفكرتك (رقم ٣)، وبعدها استخدم أي أمر من الـ١٣.

قبل لا تبدأ: ٣ أشياء

  1. 1المشروع مو مالي: صاحبه المطوّر Jake Schincariol، مجاني برخصة MIT، بدون تسجيل ولا API key.
  2. 2ما يدخل حسابك ولا ينشر بروحه. يكتب ويحلل بس، والقرار الأخير بيدك.
  3. 3تحتاج Claude Code على جهازك (Pro وفوق أو حساب Console). ما عندك؟ الصق أي ملف SKILL.md من المشروع بأول محادثة مع Claude ويشتغل، بس بدون أدوات التقييم.
