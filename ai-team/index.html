A Claude Projects الأسهل · The easy way

  1. 1افتح claude.ai/projects واضغط + New project، وسمّه «My AI Team».Open claude.ai/projects → + New project → name it “My AI Team”.
  2. 2حمّل الملف من الزر فوق. داخل المشروع اضغط + وارفع AI-TEAM.md.Download the file above. In the project click + and upload AI-TEAM.md.
  3. 3اضغط Set project instructions، الصق هذا النص، ثم Save instructions.Click Set project instructions, paste this text, then Save instructions.
    Your operating manual is the file AI-TEAM.md in this project's knowledge. Before your first reply in EVERY chat, read it completely and follow it. Also read profile.md if it exists. If AI-TEAM.md is missing, tell me before doing anything else.
  4. 4افتح Customize → Connectors → Discover. ابحث عن كل كونكتر واضغط Connect ووافق. القائمة تحت.Customize → Connectors → Discover. Search each connector → Connect → approve. List below.
  5. 5تأكد من Settings → Capabilities إن خيار Code execution and file creation (أو Create and edit files) شغّال. هذا اللي يسوي ملفات PowerPoint و Word.Settings → Capabilities: make sure Code execution and file creation (or Create and edit files) is on. It creates PowerPoint and Word files.
  6. 6للبحث العميق: داخل المحادثة اضغط + ثم Research. يحتاج Web search وخطة مدفوعة.For deep research: in a chat click + → Research. Needs web search and a paid plan.
  7. 7افتح محادثة جديدة داخل المشروع واكتب هذي الكلمة، وجاوب على الأسئلة.Open a new chat inside the project, send this word, answer the questions.
    Start
  8. 8بعد الأسئلة يعطيك Profile Card. انسخه واحفظه باسم profile.md وارفعه للمشروع (نفس زر +). بدونه ما يتذكر ذوقك بالمحادثات الجاية.You get a Profile Card. Save it as profile.md and upload it to the project (same +). Without it, new chats forget your taste.

B Claude Code للمونتير · For the Editor

  1. 1نزّل تطبيق Claude للكمبيوتر وسجّل دخول بحسابك المدفوع، ثم افتح تبويب Code. ما تحتاج تيرمنال.Install the Claude desktop app, sign in with your paid account, open the Code tab. No terminal needed.
  2. 2سوّ مجلد اسمه My-AI-Team، حط فيه AI-TEAM.md وغيّر اسمه إلى CLAUDE.md.Create a folder My-AI-Team, put AI-TEAM.md in it, rename it to CLAUDE.md.
  3. 3ركّب FFmpeg (للمونتير). Windows: افتح PowerShell وشغّل هذا الأمر.Install FFmpeg (for the Editor). Windows: open PowerShell and run this.
    winget install -e --id Gyan.FFmpeg
  4. 4Mac: ركّب Homebrew أولا من brew.sh، ثم شغّل هذا الأمر بالتيرمنال.Mac: install Homebrew first from brew.sh, then run this in Terminal.
    brew install ffmpeg
  5. 5اقفل التيرمنال وافتحه من جديد، واكتب هذا الأمر. لازم يطلع رقم نسخة.Close and reopen the terminal, then run this. It must print a version number.
    ffmpeg -version
  6. 6بتبويب Code: اختر Local، ثم Open folder… واختر My-AI-Team. اكتب Start.In the Code tab: choose Local → Open folder… → pick My-AI-Team. Type Start.
  7. 7الكونكترز اللي ربطتها بـ claude.ai تظهر هنا بنفس الحساب. Metricool ممكن تضيفه بأمر واحد.Connectors you added on claude.ai show up here with the same account. Metricool can be added with one command.
    claude mcp add --transport http metricool https://ai.metricool.com/mcp

C المونتير من الجوال Editor from your phone (Remote Control)

  1. 1أولا خلص مسار B (الكمبيوتر لازم يكون شغال ومفتوح عليه المجلد).Finish path B first (your computer must stay on).
  2. 2ركّب Claude Code بالتيرمنال. على Windows افتح PowerShell وشغّل:Install Claude Code in a terminal. Windows PowerShell:
    irm https://claude.ai/install.ps1 | iex
  3. 3على Mac افتح Terminal وشغّل:On Mac open Terminal and run:
    curl -fsSL https://claude.ai/install.sh | bash
  4. 4افتح تيرمنال داخل مجلد My-AI-Team واكتب claude، وسجّل دخول. بعدها اكتب هذا الأمر داخل الجلسة.Open a terminal inside My-AI-Team, run claude, sign in. Then type this inside the session.
    /remote-control
  5. 5على الجوال: نزّل تطبيق Claude (iOS أو Android)، سجّل بنفس الحساب، اضغط Code واختر الجلسة.On your phone: install the Claude app (iOS or Android), sign in with the same account, tap Code, pick the session.
  6. 6صوّر أو أرفق الفيديو من الجوال بالتطبيق. ينتقل للكمبيوتر والمونتير يشتغل عليه هناك، والنتيجة تنحفظ بمجلد My-AI-Team.Attach the video from your phone in the app. It is downloaded to your computer, the Editor works on it there, the result is saved in My-AI-Team.

الجوال يتحكم بالجلسة اللي على كمبيوترك. إذا قفلت الكمبيوتر أو انقطع النت يوقف. · Your phone controls the session running on your computer. If the computer is off or offline it stops. docs

إذا صار خلل · If something breaks

  1. !ما شغّل الاجنتس / رد عادي
    تأكد إن AI-TEAM.md مرفوع بالمشروع وإنك فتحت المحادثة داخل المشروع.    Replies like a normal chat
    Check AI-TEAM.md is in the project and the chat was opened inside it.
  2. !الكونكتر ما يشتغل
    Customize → Connectors: افصله واربطه من جديد، وبالمحادثة شغّله من قائمة Connectors.    A connector does not work
    Customize → Connectors: disconnect, reconnect, then switch it on from the chat’s Connectors menu.
  3. !المونتير يقول ما يقدر يقص الفيديو
    المونتير يقص بس بمسار Claude Code (الخطوات B). في Projects يعطيك خطة وأوامر.    Editor says it cannot cut video
    Cutting works only in Claude Code (path B, or from your phone via C). In Projects it gives you a plan and commands.
