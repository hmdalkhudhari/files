# ربط Metricool وvidIQ (مرة وحدة، من المتصفح أو تطبيق الكمبيوتر)

## Metricool (الجدولة والأرقام) — ببلاش
1. سوّ حساب بـmetricool.com. المجاني: براند واحد، انستقرام + تيكتوك + يوتيوب. لينكدإن يبي خطة مدفوعة.
2. داخل Metricool اربط حساباتك (Connections): سجّل دخول بكل منصة ووافق. انستقرام الأحسن يكون Business أو Creator.
3. بـclaude.ai: Customize ← Connectors ← زر + ← دوّر Metricool ← Connect ← سجّل دخول بحساب Metricool ووافق.
4. الربط يمشي على حسابك كله: الكمبيوتر والآيباد والتلفون.
5. افتح محادثة جديدة وقول «شلون أرقامي».

## vidIQ (يوتيوب) — اختياري
1. سوّ حساب بـvidiq.com بنفس حساب Google حق القناة، واربط القناة.
2. بـclaude.ai: Customize ← Connectors ← زر + ← دوّر vidIQ ← Connect ← سجّل دخول.
3. كل طلب من vidIQ ياكل من رصيد حسابك هناك (حسب خطتك).

## إذا ما اشتغل
- فشل تسجيل الدخول: Customize ← Connectors ← افتح الأداة ← Disconnect، وبعدها Connect من جديد.
- خطة Claude المجانية تسمح بكونكتر واحد بس. شركة التسويق تبي Pro.
- بالمحادثة الأداة مطفية؟ زر + تحت ← Connectors ← فعّل الأداة.
