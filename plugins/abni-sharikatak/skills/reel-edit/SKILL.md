# مونتاج الفيديوهات العادية (شخص يتكلم) بهوية الشركة

المحرّك = بلقن **majed-video** (سكل `video-ad-editor`). هالسكل يضيف فوقه: هوية الشركة من ملف واحد + قواعد مجرّبة.

## الفريق
هالسكل = قسم «المونتير» بشركة التسويق (بلوجن abni-sharikatak). القواعد العامة بسكل `ceo` ← `references/team-guide.md`.
- قبل التسليم: «قائمة خلص» حق قسمك بالدليل، وسلّم بصيغة: تم / الملفات / يحتاجك / التالي.
- صحّحك صاحب الشركة؟ طبّق قاعدة ٦ بسكل `ceo` (بالمحادثة: سطر جاهز يضيفه لـ«قواعدنا» بالبطاقة).

## قبل أي شي
0. **كمبيوتر بس.** هالسكل يشتغل بـCowork أو Claude Code على كمبيوتر، ومجلد الشركة مفتوح. بالآيباد أو التلفون؟ قوله «هذا يبي كمبيوتر» واقترح سكل `motion` بداله، ووقف.
   **أول مرة؟** ما فيه `brand/brand.json` أو `setup_done` = false: سوّ الهوية بسكل `company-builder` (الخطوة ٢)، وبعدين كمّل.
1. **المجلدات:** `<kit>` = مجلد الشركة المفتوح (فيه `brand/brand.json`). `<tools>` = مجلد `tools/` بسكل `reel-edit` (جنب ملفه: `find / -path "*reel-edit/tools/brand_to_theme.py" 2>/dev/null | head -1`).
2. **افحص الهوية:** `python <tools>/brand_to_theme.py <kit> --check`. فيه ❌؟ قل له المشكلة بسطر وكيف يصلحها، ووقف. فيه ⚠️ بس؟ قلها له بسطر وكمّل.
3. **مجلد شغل لكل فيديو:** `<work>` = مجلد مؤقت باسم الفيديو. اكتب الهوية فيه:
   `python <tools>/brand_to_theme.py <kit> <work>`
   هذا يكتب `theme.json` (للمحرّك) و`house.json` (إعدادات إضافية) وينسخ الشعار.
4. **المؤثرات:** ما فيه ملفات بـ`<kit>/sfx`؟ شغّل `python <tools>/get_sfx.py <kit>`.
5. **البلقن:** مو مثبّت majed-video؟ قل له: «لازم تثبت أداة المونتاج majed-video مرة وحدة: Customize ← Plugins ← نفس متجر حمد ← majed-video ← Install.» ووقف.

## الشغل
- امش على سكل `video-ad-editor` من بلقن majed-video خطوة خطوة، بس:
  - **⛔ لا تفتح صفحة اختيار الذوق ولا تسأل عن الألوان** — الهوية جاهزة بـ`<work>/theme.json`. لا تغيّرها إلا بطلب صريح.
  - طبّق `house.json` (الشعار، المقدمة، الختام، الموسيقى، التسريع، عدد المؤثرات) و**كل** قواعد `references/rules.md`.
  - قواعد الشركة الخاصة بـ`house_rules` داخل brand.json تغلب أي قاعدة عامة.
- **معاينة قبل الرندر الكامل:** أول ٥-١٠ ثواني بجودة خفيفة (بالكابشن والحركة والصوت) ← وريه ← بعد موافقته الرندر الكامل.
- **التسليم:** `<folders.ready>/<اسم قصير>/`: الفيديو النهائي + الغلاف + `caption.md` (كابشن المنشور) + ملف `srt`. الخام يبقى مكانه.
- ⛔ لا نشر ولا جدولة. التسليم ملف بس.
