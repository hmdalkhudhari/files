# موشن قرافيكس على الصوت بهوية الشركة

المحرّك = بلقن **majed-video** (سكل `motion-video`، المحرّك بمجلد `video-ad-editor/motion`). هالسكل يضيف: هوية الشركة من ملف واحد + قواعد مجرّبة لفيديو الصوت.

## الفريق
هالسكل = قسم «الموشن» بشركة التسويق (بلوجن abni-sharikatak). القواعد العامة بسكل `ceo` ← `references/team-guide.md`.
- قبل التسليم: «قائمة خلص» حق قسمك بالدليل، وسلّم بصيغة: تم / الملفات / يحتاجك / التالي.
- صحّحك صاحب الشركة؟ طبّق قاعدة ٦ بسكل `ceo` (بالمحادثة: سطر جاهز يضيفه لـ«قواعدنا» بالبطاقة).

## قبل أي شي
0. **كمبيوتر بس.** هالسكل يشتغل بـCowork أو Claude Code على كمبيوتر، ومجلد الشركة مفتوح. بالآيباد أو التلفون؟ قوله «هذا يبي كمبيوتر» واقترح سكل `motion` بداله، ووقف.
   **أول مرة؟** ما فيه `brand/brand.json` أو `setup_done` = false: سوّ الهوية بسكل `company-builder` (الخطوة ٢)، وبعدين كمّل.
1. **المجلدات:** `<kit>` = مجلد الشركة المفتوح (فيه `brand/brand.json`). `<tools>` = مجلد `tools/` بسكل `reel-edit` (جنب ملفه: `find / -path "*reel-edit/tools/brand_to_theme.py" 2>/dev/null | head -1`).
2. **افحص الهوية:** `python <tools>/brand_to_theme.py <kit> --check` (❌ = وقف وقل له يصلح، ⚠️ = قلها بسطر وكمّل).
3. **مجلد شغل:** `python <tools>/brand_to_theme.py <kit> <work>` ← `theme.json` + `house.json` + الشعار.
4. **المؤثرات:** ما فيه ملفات بـ`<kit>/sfx`؟ `python <tools>/get_sfx.py <kit>`.
5. **البلقن:** مو مثبّت majed-video؟ «لازم تثبت أداة المونتاج majed-video مرة وحدة: Customize ← Plugins ← نفس متجر حمد ← majed-video ← Install.» ووقف.

## الشغل
1. **الصوت:** التسجيل من المستخدم (صوته هو، مو صوت مولّد إلا إذا طلب). حوّله نص بكلمات موقّتة، وصحّح اللهجة.
   - فيه إعادات؟ خذ أحسن تيك لكل جملة، وفراغ ٠.٢٥ ث بين المقاطع. اكتب التوقيتات بزمن الملف الأصلي.
   - تسريع خفيف (`speed_up_pct`) وloudnorm على `loudness_lufs`.
2. **الخطة (ستوري بورد):** قسّم الكلام لمشاهد ٢-٤ ث، كل مشهد = فكرة وحدة بعنصر رئيسي واحد. وريه الخطة بسطور قصيرة.
3. **معاينة:** أول ١٠ ثواني بالصوت والحركة ← وريه ← بعد موافقته الرندر الكامل.
4. امش على سكل `motion-video` من majed-video للمحرّك والأوامر، بس:
   - **⛔ لا تسأل عن الألوان ولا تفتح صفحة الذوق** — الهوية بـ`<work>/theme.json`.
   - طبّق `house.json` و**كل** `references/rules.md`، وقواعد `house_rules` تغلب.
5. **التسليم:** `<folders.ready>/<اسم قصير>/`: الفيديو + الغلاف + `caption.md`. ⛔ لا نشر ولا جدولة.
