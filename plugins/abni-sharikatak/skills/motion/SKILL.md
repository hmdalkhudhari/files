# موشن على موسيقى (بدون صوت)

المحرّك: `engine/make_motion.py` بمجلد `engine/` جنب هالملف (ما لقيته؟ `find / -path "*motion/engine/make_motion.py" 2>/dev/null | head -1`). يحتاج Pillow + numpy + ffmpeg.

## الفريق
هالسكل = قسم «الموشن» بشركة التسويق (بلوجن abni-sharikatak). القواعد العامة بسكل `ceo` ← `references/team-guide.md`.
- قبل التسليم: «قائمة خلص» حق قسمك بالدليل، وسلّم بصيغة: تم / الملفات / يحتاجك / التالي.
- صحّحك صاحب الشركة؟ طبّق قاعدة ٦ بسكل `ceo` (بالمحادثة: سطر جاهز يضيفه لـ«قواعدنا» بالبطاقة).

## قبل أي شي
1. **الهوية:** نفس خطوة الهوية بسكل `designer` بالضبط (مجلد ← brand/brand.json، محادثة ← سطر «الهوية» بالبطاقة + شعار مرفوع إن وجد).
2. **الأدوات:** `python -c "import PIL, numpy"` و`ffmpeg -version`. ما فيه ffmpeg؟ `pip install imageio-ffmpeg` (المحرّك يلقاه بروحه). العربي مقطع؟ `pip install arabic-reshaper python-bidi`.

## حركات الموشن (١٦ حركة، تشتغل بالآيباد بدون كمبيوتر)
أي مشهد تقدر تخليه حركة بدل الكلام العادي: `{"motion": "<الاسم>", ...}` بـspec.json. الأسماء والبيانات بأول `engine/motions.py`:
kinetic-words (هوك كلمة كلمة) · title-rise (عنوان) · gold-box (كلمة على مربع بلون التمييز، `#كلمة#`) · big-word · typewriter · countdown · steps (خطوات) · checklist · before-after · counter (عدّاد) · ring (نسبة) · bar-chart · stars · price-tag (سعر وعرض) · quote · comment-cta («اكتب ملف بالتعليقات»).
- `"seconds": 4` لكل مشهد حركة إذا تبي مدة غير الافتراضي (٣.٦).
- أي رقم (counter, ring, bar-chart, stars, price-tag) لازم يكون حقيقي من صاحب الشركة.
- المنصوح: المشهد الأول kinetic-words أو big-word، والأخير comment-cta أو `{"end": true}`.

## الموسيقى
- عنده ملف موسيقى (mp3/m4a/wav) يملك حقه أو مجاني للاستخدام التجاري؟ استخدمه، والقصّات تمشي على الإيقاع.
- ما عنده؟ **المنصوح:** نطلع الفيديو بدون موسيقى وهو يحط صوت ترند من انستقرام/تيكتوك وقت النشر (يوصل لناس أكثر وما فيه مشاكل حقوق). قول له هالشي بسطر.
- ⛔ لا تنزّل أغاني عليها حقوق.

## الشغل
1. اكتب السكربت: ٤-٧ مشاهد، كل مشهد جملة وحدة واضحة (٣-٨ كلمات)، والمجموع ١٢-٢٥ ثانية. وريه السطور ويوافق.
   - المشهد ١ = الهوك: أقوى جملة أو رقم، يخاطب المشاهد («أنت»، «محلك»). اكتب ٣ هوكات وقيّمها من ١٠٠ (قصير ٢٠، رقم أو اسم محدد ٢٠، رهان أو سؤال ٢٠، المعلومة بالبداية ٢٠، يكلم المشاهد ٢٠). تحت ٥٠ = غيره. اختار الأعلى وقل درجته.
   - مشهد رقم: `"number"` (من صاحب الشركة أو مصدر حقيقي بس).
   - صورة منتج حقيقية: `"image"`.
   - آخر مشهد: `{"end": true}` (شعار + خانة تعليق بكلمة `outro.comment_word` أو «تابعنا»).
2. اكتب `spec.json` (الشكل بأول `make_motion.py`) وشغّل `python <engine>/make_motion.py spec.json`.
3. **افحص قبل التسليم:** طلّع فريمات (0.3، 1.5، النص، آخر ثانية) بـffmpeg وشوفها: الكلام يتقرى؟ ما يطلع برا؟ الصوت لآخر الفيديو؟
4. سلّم الفيديو + كابشن المنشور. بالمحادثة أرسله ملف (يضغط عليه ← Save to Photos أو Share ← Save Video).
5. ⛔ لا نشر ولا جدولة إلا بطلب صريح.

## قواعد
- كلام قليل وواضح، يتقرى بثانية. سطر صغير رمادي + سطر كبير فيه كلمة ملوّنة.
- أرقام غربية. بدون إيموجي.
- ولا رقم أو معلومة من عندك.
- `house_rules` بـbrand.json تغلب.
