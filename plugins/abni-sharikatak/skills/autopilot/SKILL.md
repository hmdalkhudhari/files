# الطيار الآلي

الفكرة: صاحب الشركة ما يطلب كل شي بإيده. الشغل يجيه جاهز بمواعيد اختارها، وهو يقول «إي» على النشر بس.

## الثوابت (ما تتغير)
- ⛔ ولا مهمة تنشر أو تجدول أو ترسل رسائل أو تشتري بروحها. كل مهمة تجهّز وتوقف عند «ينتظرك».
- كل مهمة تكتب داخل مجلد الشركة بس (`company/`، `Designs/`، `Videos/`). ما تلمس شي برا.
- مهمة واحدة لكل شغلة. ما تكرر مهمة موجودة: افحص القائمة أول.

## المهام (المواعيد من البطاقة، وهذي الافتراضية)
| المهمة | متى | شنو تسوي | وين تحفظ |
|---|---|---|---|
| ملخص الصبح | كل يوم <ساعة الملخص> | أمر `morning` | `company/reports/<التاريخ>-morning.md` |
| منشور اليوم | كل يوم ١١ الصبح (أيام النشر حسب «منشورات بالأسبوع») | الكاتب يكتب والمصمم يصمم منشور واحد جاهز (صور + كابشن) ويحطه «ينتظرك» | `Designs/Ready/<التاريخ>-<اسم>/` |
| الباحث | كل ٣ أيام ١٠ الصبح | ٥ أفكار من مجاله (ترندات + منافسين) مرتبة، لكل فكرة سطر «ليش» | `company/work/<التاريخ>-ideas.md` |
| القياس | كل يوم ١ الظهر | لكل منشور نزل قبل ٤٨ ساعة: الأرقام من Metricool + سطر درس | `company/reports/<التاريخ>-48h.md` |
| اجتماع الأسبوع | <يوم وساعة الاجتماع> | أمر `weekly`: النمو، الأفكار، التطوير، شنو نجح وشنو لا، خطة الأسبوع | `company/reports/<التاريخ>-weekly.md` |
| التنظيف | كل يومين ٣ الفجر | سكل `cleanup` | `company/reports/cleanup-log.md` |

## شلون تبنيها
**بالكمبيوتر (Cowork، مجلد الشركة مفتوح):**
1. افتح المهام المجدولة (`/schedule` أو صفحة Scheduled) وأنشئ كل مهمة من الجدول: الاسم بالعربي، النص = «إنت <اسم المدير> (سكل ceo من بلوجن abni-sharikatak) بمجلد شركة <الاسم>. سوّ: <شنو تسوي>. احفظ بـ<وين>. لا تنشر ولا تجدول ولا ترسل شي.»، التكرار حسب الجدول، والمجلد = مجلد الشركة، ووضع الموافقة = يسأل قبل أي شي برا المجلد.
2. بعد ما تخلص: اعرض له الجدول بسطر لكل مهمة، وقل: «تشتغل حتى لو الكمبيوتر طافي، إلا اللي تحتاج ملفات عندك (المونتاج).»
3. ما قدرت تنشئها بنفسك؟ لا تخمن. أعطه نص كل مهمة جاهز وقل: «افتح Scheduled ← Set up manually ← الصق هذا».

**بالمحادثة (آيباد، تلفون):**
- أعطه نص كل مهمة جاهز بمربع نسخ، وقل: «من المتصفح claude.ai ← Cowork ← Scheduled ← Set up manually ← الصق النص واختار الوقت». مهمة بكل رسالة لين يقول «تم». (المصدر: support.claude.com/en/articles/13854387)
- ما يبي يسويها؟ عادي، كل شي يشتغل بالطلب: «ملخص الصبح»، «اجتماع الأسبوع»، «أفكار».

## أوامره
- «وقّف الطيار الآلي»: أوقف (Pause) كل المهام، وقل له شلون يرجعها.
- «غيّر موعد …»: عدّل المهمة نفسها، لا تنشئ ثانية.
- «شنو المهام المجدولة»: اعرض الجدول وحالة كل وحدة.
