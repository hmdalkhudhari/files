# إعداد الهوية (أول مرة)
صاحب الشركة لحاله وما يعرف شي تقني: كلّمه ببساطة، سؤال واحد بكل مرة.
1. «قبل أول تصميم أبي أعرف هويتكم. عطني رابط حسابكم أو موقعكم، أو صورتين ثلاث من تصاميمكم، أو قول ألوانكم بالكلام (مثل: أسود وذهبي).»
   - رابط موقع: اجلب الصفحة وطلّع الألوان (theme-color، ألوان CSS المتكررة) والشعار.
   - صور: طلّع ٥ ألوان (خلفية، كلام، تمييز، تمييز أغمق، رمادي) بتباين مقروء (Pillow: quantize).
   - انستقرام ما ينفتح؟ اطلب سكرين شوت من البروفايل.
   - بالكلام: حوّله أكواد بتباين مقروء.
2. «عطني الشعار، الأحسن PNG بدون خلفية.» ما عنده؟ كمّل بدونه.
3. اسم الشركة واليوزر.
4. اكتب `brand.json` (نفس شكل القالب) وسوّ معاينة: كاروسيل سلايدين (cover + cta) بالمحرّك. وريه: «جذي بتطلع تصاميمك، تمام؟» عدّل لين يوافق.
5. حط `"setup_done": true`.
   - بالكمبيوتر: احفظه بـ`brand/brand.json` والشعار بـ`brand/logo/`.
   - بالآيباد/claude.ai: أرسل له `brand.json` والشعار كملفات، وقل له: «نزّل الملفين وارفعهم بملفات المشروع (Project ← Files ← +) عشان أتذكرهم كل مرة.» وإذا عنده قديم: «امسح القديم وحط الجديد.»
