# قواعد التصاميم (مجرّبة)

## عام
- لون تمييز واحد بكل تصميم، على كلمة أو رقم واحد بالسطر (`*كلمة*`). مو كل شي ملوّن.
- أرقام غربية (1 2 3 و63%) لأنها أوضح بالحجم الكبير. الرقم وكلمته («ألف»، «مليون») بنفس السطر.
- بدون إيموجي بالتصاميم. صور حقيقية بدالها.
- **ولا رقم أو معلومة من عندك.** الرقم لازم يكون من صاحب الشركة أو مصدر حقيقي. ما فيه؟ اكتب الجملة بدون رقم، أو اكتب «مثال» تحته.
- صحح الإملاء (جائزة مو جايزة، إلخ).
- لا تكرر نفس القالب قبل ٥-٧ منشورات من نفس النوع: بدّل نوع السلايدات وأماكن الصور. سجّل كل قالب بـ`assets-used.md` بملفات المشروع (عطه الملف معدّل كل كم منشور يبدله).
- **الكفر بالشبكة:** ٢-٤ كلمات، لا شي بالركن اليمين فوق (آخر ١٥٪ عرض × أول ١٢٪ طول)، المهم داخل مربع ٣:٤ بالنص.
- الشعار حسب `logo.show` (الافتراضي على أول سلايد بس). اليوزر بآخر سلايد.

## الكاروسيل (6-10 سلايدات)
1. **الغلاف:** رقم واحد كبير، أو معلومة غلط مشهورة، أو نتيجة. ٢-٦ كلمات. مو عنوان عام («نصايح تسويق» ضعيف).
2. **السلايد ٢:** الدليل أو ليش يهمك (stat أو صورة حقيقية).
3. **٣ إلى قبل الأخير:** نقطة وحدة بكل سلايد، عنوان + سطرين بالكثير (point / list)، ٢٥ كلمة بالكثير. كل سلايد يخلص بسؤال صغير أو تشويق يجاوبه اللي بعده (قصة متصلة).
4. **الأخير:** دعوة (cta): كلمة يكتبونها بالتعليقات ويوصلهم شي يستاهل، أو «أرسلها لصاحبك اللي…»، أو «احجز / اطلب: الرابط بالبايو».
- الموضوع يهم أي أحد، وبعدين يربطه بمنتج الشركة أو خدمتها.

## الستوري (3-5 باليوم)
- فوق ٢٦٠ بكسل وتحت ٣٦٠ بكسل فاضيين (أزرار انستقرام). المحرّك يحسبها.
- أنواع تتبدل: سؤال/تصويت «خمّن» (`question`، يخلي مكان الستيكر فاضي، الستيكر ينحط بالتطبيق)، نصيحة (`cover`)، رقم (`stat`)، كواليس (صورة حقيقية)، عرض.
- ستوري وحدة = فكرة وحدة.

## الكابشن
- أول ١٢٥ حرف = الوعد أو الهوك. طلب واحد بس. ٣-٥ هاشتاقات بالكثير آخر شي. بدون رابط.

## البوست الواحد
- `cover` أو `stat` أو `quote`. كلام قليل يتقرى بثانية.

## تيكتوك
- الكاروسيل نفسه ينزل «صور» بتيكتوك. الستوري 1080x1920 ينفع كصورة بتيكتوك بعد.
