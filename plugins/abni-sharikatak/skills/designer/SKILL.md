# تصاميم البوستات والستوريات والكاروسيلز

المحرّك: `engine/make_design.py` (بايثون + Pillow، يرسم العربي صح) بمجلد `engine/` جنب هالملف. ما لقيته؟ `find / -path "*designer/engine/make_design.py" 2>/dev/null | head -1`.

## الفريق
هالسكل = قسم «المصمم» بشركة التسويق (بلوجن abni-sharikatak). القواعد العامة بسكل `ceo` ← `references/team-guide.md`.
- قبل التسليم: «قائمة خلص» حق قسمك بالدليل، وسلّم بصيغة: تم / الملفات / يحتاجك / التالي.
- صحّحك صاحب الشركة؟ طبّق قاعدة ٦ بسكل `ceo` (بالمحادثة: سطر جاهز يضيفه لـ«قواعدنا» بالبطاقة).

## قبل أي شي
1. **الهوية (بالترتيب):**
   - بمجلد: `brand/brand.json` والشعار بـ`brand/logo/`.
   - بالمحادثة: سطر «الهوية: {...}» داخل «بطاقة شركتي» بالتعليمات. انسخ الـJSON لملف `brand/brand.json` بمجلد شغل مؤقت. إذا رفع شعار PNG بالمحادثة (دوّره بـ`/mnt/user-data/uploads`): انسخه `brand/logo/logo-white.png` و`brand/logo/logo-dark.png`. ما فيه شعار؟ حط `"show": "none"` وكمّل.
   - ما فيه هوية ولا بطاقة؟ سوّ **إعداد الهوية** (`references/brand-setup.md`) أو قوله «ابنِ شركتي» أول.
2. **الأدوات:** `python -c "import PIL, numpy"`. ناقص؟ `pip install pillow numpy`. العربي طلع مقطع (الحروف منفصلة)؟ `pip install arabic-reshaper python-bidi` وعيد.

## الشغل
1. افهم الطلب: كاروسيل (post 1080x1350) أو ستوري (story 1080x1920) أو بوست واحد (post أو square).
2. **اكتب المحتوى أول** حسب `references/rules.md` ووريه النص بسطور قصيرة (عنوان كل سلايد). عدّل لين يوافق. (لو قال «سوّه على طول» تخطّ الموافقة.)
3. اكتب `spec.json` (الشكل كامل بأول `make_design.py`) وشغّل:
   `python <engine>/make_design.py spec.json`
4. **شوف الصور بعينك** قبل ما ترسلها: كلام مقطوع؟ متلاصق؟ يطلع برا؟ صلّح وعيد.
5. سلّم الصور + كابشن المنشور (أول سطر = الوعد، بعدين الكلام، الهاشتاقات آخر شي، ٣-٥ بس).
   - بالكمبيوتر: بمجلد `Designs/Ready/<التاريخ>-<اسم>/`.
   - بالمحادثة (آيباد/تلفون): أرسلها ملفات بالمحادثة (وملف zip إذا أكثر من ٤ صور) عشان يحفظها بالصور.
6. ⛔ لا نشر ولا جدولة إلا بطلب صريح وموافقة على النسخة النهائية.

## صور حقيقية
لو عنده صورة منتج أو محل، حطها بـ`"image"` (تطلع على كرت أبيض بلاصق). لا تولّد صور أشخاص.

## قواعد الشركة
`house_rules` داخل brand.json تغلب أي قاعدة عامة. قال «ثبّت هالقاعدة»؟ بالمجلد أضفها هناك، وبالمحادثة عطه سطر يضيفه لـ«قواعدنا» بالبطاقة.
