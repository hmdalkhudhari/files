# المساعدة: إذا طلع لك كذا، سوّ كذا

صاحب الشركة مو تقني. لقّ مشكلته بالجدول، وعطه الحل **خطوة وحدة بالمرة**، وانتظر «تم» قبل الخطوة اللي بعدها. أرسل صورة شاشة؟ اقرأها أول.
ما لقيت مشكلته هني؟ لا تألف أزرار. قوله يرسل صورة الشاشة، أو يكلم حمد.

| إذا طلع لك / صار | سوّ |
|---|---|
| ما لقيت Customize أو Plugins بتطبيق الآيباد أو التلفون | التركيب من المتصفح بس: افتح Safari ← claude.ai ← سجّل دخول. Customize بالقائمة على اليسار. بعد التركيب كل شي يشتغل بالتطبيق. |
| ما وصلني إيميل الدخول | دوّر بالـSpam (Junk) على إيميل من @mail.anthropic.com عنوانه «Secure link to log in to Claude.ai». ما لقيته؟ انتظر دقايق وعيد. |
| فتحت رابط الدخول بجهاز ثاني | يطلع لك كود. اكتبه بالجهاز اللي كنت تسجل فيه. |
| دخلت بس ما فيه اشتراك | سجلت بإيميل غلط. اطلع (Log out) وادخل بالإيميل اللي عليه اشتراك Pro. |
| ما فيه Plugins أو Add marketplace | البلوجنز للاشتراك المدفوع بس (Pro أو أعلى). |
| كتبت اسم المتجر وطلع خطأ | الصق الرابط كامل: https://github.com/hmdalkhudhari/files (بدون مسافة بالأول أو الآخر). |
| المتجر انضاف بس ما شفت البلوجن | Customize ← Plugins ← Discover (أو المتجر نفسه) ← «ابنِ شركتك» ← Add أو Install. |
| Claude ما يستخدم البلوجن | ١) تأكد إن البلوجن مو مطفي (Disable plugin). ٢) افتح محادثة جديدة. ٣) اكتب: «استخدم بلوجن abni-sharikatak وابنِ شركتي». |
| يقول ما يقدر يشغّل كود، أو ما يطلع صور وفيديو | Settings ← Capabilities ← فعّل Code execution and file creation (اسمها بالشكل الجديد Create and edit files). وافتح محادثة جديدة. |
| السكلز رمادية (Greyed out) | نفس اللي فوق: فعّل تنفيذ الكود. |
| كتبت / بالتلفون وما طلعت الأوامر | عادي. اكتب طلبك بالكلام: «ابنِ شركتي»، «سوّ كاروسيل عن…». |
| عندي سكلز قديمة (company-design, company-motion-music, company-account) | Customize ← Skills ← اطفها أو امسحها. البلوجن فيه نسخها الجديدة، والقديمة تلخبط. |
| نزّلت ملف .url أو .zip أو .plugin | ما تحتاج ولا ملف. التركيب بالرابط بس. امسح الملف. |
| ما لقيت Instructions for Claude | Settings ← Your Claude (بالشكل القديم: Account). الخانة اسمها Instructions for Claude. |
| Claude نسى شركتي أو يسألني من جديد | البطاقة مو محفوظة. قول «ابنِ شركتي» ← بيعطيك البطاقة ← الصقها بـInstructions for Claude واحفظ ← محادثة جديدة. |
| أبي أغيّر ألواني أو أضيف موظف | قول «غيّر ألواني» أو «أضف موظف». يعطيك بطاقة جديدة، تبدل القديمة فيها. |
| الشعار ما طلع بالتصميم | الشعار ما ينحفظ بالبطاقة. ارفعه (PNG) بنفس المحادثة وقول «حط الشعار». |
| Metricool أو vidIQ ما انربط | Customize ← Connectors ← + ← دوّر اسمه ← Connect. فشل؟ افتحه ← Disconnect ← Connect من جديد. |
| الأداة مربوطة بس Claude ما يشوفها بالمحادثة | زر + تحت مربع الكتابة ← Connectors ← فعّلها. |
| خطة Claude مجانية وما قدرت أربط أكثر من أداة | المجاني كونكتر واحد بس. شركة التسويق تبي Pro. |
| العربي طالع حروف مقطعة | قول: «العربي مقطع، ثبّت arabic-reshaper وعيد». |
| الفيديو أو الصور ما انحفظت بالآيباد | اضغط على الملف ← Share ← Save Video (أو Save Image). |
| طلبت مونتاج فيديو مصوّر من الآيباد | هذا يبي كمبيوتر (Cowork). من الآيباد قول «سوّ فيديو موشن عن…». |
| وصلت الحد (Usage limit) | انتظر للوقت المكتوب. إذا يصير كل يوم، فكّر بـMax. |
| حمد قال فيه تحديث | Customize ← Plugins ← المتجر ← Check for updates. (إذا فعّلت Sync automatically يتحدث بروحه.) |

## قاعدة
لا تطلب كلمة سر أي حساب أبداً. إذا المشكلة بالباسورد: «سجّل دخولك بنفسك، وأنا أكمل بعدها».
