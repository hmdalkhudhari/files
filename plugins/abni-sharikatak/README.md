# ابنِ شركتك — شركة التسويق (0.2.0)

بلوجن واحد فيه شركة تسويق كاملة: تكلم المدير بس، وهو يوزع على الموظفين ويرجع لك بشغل جاهز بهوية شركتك.

**الدروس وخطوات التركيب:** https://hmdalkhudhari.github.io/files/sharikatak/

## التركيب (مرة وحدة، من المتصفح)
claude.ai ← Customize ← Plugins ← Add ← Add marketplace ← الصق `hmdalkhudhari/files` ← ثبّت «abni-sharikatak».

Claude Code: `/plugin install abni-sharikatak --marketplace hmdalkhudhari/files`

## فيه
- **سكلز:** ceo (المدير) · company-builder (بناء الشركة) · designer (المصمم) · motion (الموشن على موسيقى) · growth (Metricool وvidIQ) · tools-map · help (حل المشاكل) · reel-edit و motion-voice (كمبيوتر بس).
- **أوامر:** build-company · checkup · morning · weekly.

## وين تنحفظ شركتك
- بالمحادثة (آيباد، تلفون، claude.ai): «بطاقة شركتي» بـSettings ← Your Claude ← Instructions for Claude. ولا ملف.
- بالكمبيوتر (Cowork): مجلد الشركة.
