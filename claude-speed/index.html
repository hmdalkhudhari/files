الخطوات

رقّمتها بالترتيب، وتحت كل خطوة شنو لازم تشوف.

  1. 1

    قِس سرعة النت الحين

    افتح speedtest.net واضغط GO. سجّل رقمين: التحميل (Download) والاستجابة (Ping). بنقارن فيهم بعد الفحص.Run speedtest.net first and note Download and Ping
    شنو بتشوف: رقم بالميغابت (Mbps). لا تسكّر الصفحة، بترجع لها بالآخر.
  2. 2

    افتح الترمنال

    ويندوز: اضغط زر Windows، اكتب PowerShell، واضغط Enter. ماك: اضغط Command + Space، اكتب Terminal، واضغط Enter.Windows: Start, type PowerShell, Enter. Mac: Cmd+Space, type Terminal, Enter
    شنو بتشوف: شاشة فيها سطر ينتظر منك تكتب. بويندوز يبدأ السطر بـ PS C:\
  3. 3

    ثبّت Claude Code

    الصق الأمر المناسب لجهازك واضغط Enter. ما يطلع تقدم أثناء التنزيل، فاصبر دقيقة أو دقيقتين ولا تسكّر النافذة.Paste the command for your system and press Enter. No progress is shown
    ويندوز (PowerShell)

    irm https://claude.ai/install.ps1 | iex

    ماك / لينكس

    curl -fsSL https://claude.ai/install.sh | bash

    شنو بتشوف: يرجع السطر ينتظرك من جديد، وهذا معناه خلص.
    لو ظهر «irm is not recognized» فأنت فاتح CMD مو PowerShell. اقفله وافتح PowerShell. ولو ظهر خطأ ثاني، شوف صفحة حل المشاكل الرسمية.
  4. 4

    تأكد إنه اشتغل

    اقفل الترمنال وافتح واحد جديد، واكتب الأمر تحت.Close the terminal, open a new one, run the command

    claude --version

    شنو بتشوف: رقم نسخة، مثل 2.1.x (Claude Code). لو قال «not recognized» اقفل الترمنال وافتحه مرة ثانية.
  5. 5

    افتح كلود وسجّل دخول

    اكتب الأمر تحت. بيفتح المتصفح، سجّل دخول بحساب Claude اللي عليه الاشتراك، ووافق، وبعدها ارجع للترمنال.Run claude, sign in with your paid Claude account in the browser

    claude

    شنو بتشوف: رسالة ترحيب بالترمنال، وسطر تكتب فيه. لو سألك «تثق بهالمجلد؟» أو عن شكل الألوان، اختر الخيار الأول واضغط Enter.
  6. 6

    الصق أمر الفحص

    انسخ الأمر تحت والصقه بالترمنال (ويندوز: كليك يمين أو Ctrl+V، ماك: Command+V) واضغط Enter.Paste the prompt below and press Enter

    افحص جهازي والوايفاي وشوف شنو اللي يبطّئهم: الرام، العمليات المنسية، مجلد Temp، وإعدادات الشبكة. قبل ما تغلق أو تمسح أو تغيّر أي شي، اكتب لي القائمة واستأذني. وتأكد إن ما في شي يتعطل من شغلي. واللي لازم أسويه أنا بنفسي (مثل إعدادات الـDNS) اكتبه لي خطوات.

    شنو بتشوف: كلود يشتغل ويفحص، ويكتب لك قائمة بالأشياء اللي تبطّئ جهازك.
  7. 7

    وافق أو ارفض كل شي بكيفك

    قبل أي إغلاق أو مسح، كلود يوقف ويسألك. اقرا اللي بيسويه، واختر يسوي أو لا. الأشياء اللي لازم تسويها أنت (مثل الـDNS) يكتبها لك خطوات.Claude asks before any change. Approve or decline each one
    شنو بتشوف: أسئلة بخيارات (نعم / لا). ولو ما فهمت شي اسأله: «اشرح لي شنو هذا؟»
  8. 8

    قِس النت بعد وقارن

    ارجع لـ speedtest.net وقِس مرة ثانية، وقارن بالرقم اللي سجلته بالخطوة 1. لما تخلص اكتب /exit للخروج من كلود.Run speedtest.net again and compare. Type /exit to quit

تنبيه: النتيجة تختلف من جهاز لجهاز ومن نت لنت. الأرقام اللي بالفيديو أرقامي أنا، مو وعد بنتيجة.
